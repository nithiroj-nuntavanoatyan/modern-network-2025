Quick Reference

Common Key Patterns

  • PORT|Ethernet* — port config
  • VLAN|Vlan* — vlan config
  • BGP_NEIGHBOR|* — BGP peers
  • DEVICE_METADATA|localhost — hostname/ASN
  • ROUTE_TABLE:* — IP routes
  • NEIGH_TABLE:* — ARP entries
  • ASIC_STATE:SAI_OBJECT_TYPE_ROUTE_ENTRY:* — ASIC routes
  • COUNTERS:oid:0x* — port counters by OID

Useful SAI Counter Fields

  • SAI_PORT_STAT_IF_IN_OCTETS
  • SAI_PORT_STAT_IF_OUT_OCTETS
  • SAI_PORT_STAT_IF_IN_ERRORS
  • SAI_PORT_STAT_IF_OUT_ERRORS
  • SAI_PORT_STAT_IF_IN_DISCARDS
  • SAI_PORT_STAT_IF_OUT_DISCARDS
  • SAI_PORT_STAT_IF_IN_UCAST_PKTS
  • SAI_PORT_STAT_IF_OUT_UCAST_PKTS
Tip: Inside the SONiC container/shell prefer sonic-db-cli over raw redis-cli — it uses the DB connector config at /var/run/redis/sonic-db/database_config.json and handles Unix socket paths automatically. From outside (containerlab host) use redis-cli -h 172.20.20.2 -p 6379 -n <DB_ID>.
